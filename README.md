### 🔥 Core Architecture & Features

- **Real-Time Communication:** Instant 1:1 and group text messaging powered by custom **WebSocket** structures featuring live delivery status and read receipts.
- **Peer-to-Peer Calling:** Low-latency, high-performance video and audio calling implemented natively via **WebRTC**.
- **AI Intelligence Layer:** Integrated a contextual **AI assistant** capable of generating smart replies, assisting users with writing, and providing real-time content automation.
- **Geospatial Newsfeed:** Location-based interactive newsfeeds driven by high-efficiency geospatial index queries.
- **Cross-Platform Delivery:** Maximized code reusability using a unified design philosophy across **Next.js** for web clients and **React Native (Expo)** for mobile environments.
